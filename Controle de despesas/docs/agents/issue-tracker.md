# Rastreador de tarefas: GitHub

As tarefas deste projeto são acompanhadas no GitHub Issues de `RaphaelBarros24/pessoal`: https://github.com/RaphaelBarros24/pessoal/issues.

- O remoto GitHub autorizado é `https://github.com/RaphaelBarros24/pessoal.git`.
- Use `gh issue view` para ler tarefas e `gh issue create` para publicá-las quando solicitado pelo usuário.
- Pull requests externos não fazem parte da fila de solicitações por padrão.
- A skill `triage` usa os cinco rótulos padrão. Antes de classificar tarefas, leia `triage-labels.md`.

Registre o estado da sessão em `AGENTS.md` e `CLAUDE.md`, mantendo ambos sincronizados.
