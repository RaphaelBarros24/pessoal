# Rótulos de triagem

| Papel da skill | Rótulo no GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Aguardando avaliação |
| needs-info | needs-info | Aguardando informações |
| ready-for-agent | ready-for-agent | Especificada e pronta para um agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será implementada |

Ao aplicar um papel de triagem, use o rótulo correspondente desta tabela.
