# Documentação de domínio

Este projeto usa um único contexto (single-context).

Antes de explorar o código, leia `CONTEXT.md` na raiz do projeto e as decisões em `docs/adr/` relacionadas ao trabalho atual, quando existirem.

Se esses arquivos não existirem, prossiga sem exigir sua criação. A documentação deve surgir quando conceitos e decisões forem definidos, por exemplo com a skill `domain-modeling`.

Use os termos definidos no glossário de `CONTEXT.md`. Quando uma proposta contrariar uma decisão registrada, indique explicitamente qual ADR está sendo reconsiderado e por quê.
